# Web Technology Learning Library
Static multi-page study site (HTML5, CSS3, vanilla JS, LocalStorage) for B.Tech Web Technology. Pages: index.html, unit-1..5.html. Content lives in assets/js/data.js.
## Run locally
Open index.html, or run `python -m http.server` and visit http://localhost:8000
## Deploy to GitHub Pages
git init; git add .; git commit -m "Initial release"; git branch -M main; git remote add origin https://github.com/YOUR_USERNAME/web-technology-learning-library.git; git push -u origin main
Then: Repository Settings > Pages > Deploy from branch > main / root.
